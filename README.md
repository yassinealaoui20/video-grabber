# Video Grabber

1. Install Python 3.9+ and ffmpeg (needed to merge video + audio).
2. `pip install -r requirements.txt`
3. `python app.py`
4. Open http://localhost:5000

Keep yt-dlp updated (`pip install -U yt-dlp`), since platforms change often.
To put it online, deploy to a VPS, Render, Railway or Fly.io (not static hosting).
